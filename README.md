# 🤝 Social Projects API

A **Social Projects API** é uma solução RESTful desenvolvida em **Node.js** e **Express** para centralizar a gestão de projetos de impacto social. A aplicação permite o armazenamento de causas ativas, a receção de mensagens através de formulários de contacto e a integração de doações via PIX.

---

## 🛠️ Tecnologias Utilizadas

- **Runtime:** Node.js
- **Framework Web:** Express.js
- **Variáveis de Ambiente:** Dotenv
- **Gestor de Pacotes:** npm
- **Controlo de Versões:** Git & GitHub

---

## 📌 Funcionalidades da Aplicação

- [x] Configuração inicial da API e servidor HTTP
- [ ] Gestão e listagem de projetos sociais ativos
- [ ] Formulário de contacto e receção de mensagens
- [ ] Integração de doações via PIX
- [ ] Autenticação de utilizadores/administradores (JWT)
